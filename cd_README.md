🧠 **Image Classification Using CNN**

This is a beginner-friendly project that shows how to build an image classifier using Convolutional Neural Networks (CNN) with TensorFlow/Keras in Python.

It’s written in a Jupyter Notebook and includes all steps from loading the data to training and testing the model.

📌 **What You Will Learn**

> How to load and prepare image data
> How to build a CNN mode
>How to train and test the model
>How to show results using graphs
How to make predictions

📝 **Files in This Project**

image-classification-using-cnn-for-beginners.ipynb → the main notebook

README.md → this file

📊 **Dataset Used**

This project uses a simple dataset like MNIST or CIFAR-10 which is already available in Keras — no need to download anything manually!
